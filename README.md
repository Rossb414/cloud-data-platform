# Cloud Data Platform

A full-stack cloud data processing and analysis platform.

The application allows users to upload structured datasets, process them, calculate statistical analyses, and view the results through a web interface.

## Project Status

🚧 Currently in development.

## Planned Technology Stack

- Python
- FastAPI
- PostgreSQL
- React
- Docker
- GitHub Actions
- Cloud deployment

## Planned Features

- User authentication
- CSV dataset uploads
- Server-side file validation
- Dataset processing
- Statistical analysis
- Data visualisation
- Dataset history
- REST API
- Background processing
- Automated testing
- CI/CD
